# ReactComponents.com Elements

This skill ensures that whenever you are designing or implementing standard UI sections in React, you draw inspiration from the clean, highly functional component structures found on https://www.reactcomponents.com/.

## Instructions

1. **Leverage Pre-built Patterns:** When the user requests standard UI blocks (e.g., pricing tables, feature grids, hero sections, auth forms, footers), design them with the professional clarity and structure characteristic of ReactComponents.com.
2. **Component Characteristics:** Ensure the generated components are:
   - Built with React (or Next.js) and seamlessly styled with Tailwind CSS.
   - Modular, self-contained, and perfectly suited for a "copy-paste" workflow.
   - Fully responsive, ensuring they look great on mobile, tablet, and desktop viewports right out of the box.
3. **Implementation Standards:** 
   - Keep the code concise and avoid over-engineering.
   - Use standard Tailwind utility classes to achieve the visual design without relying on complex custom CSS.
   - Maintain accessibility standards (semantic HTML tags, proper contrast, and aria attributes).

## Trigger Conditions
Invoke this skill automatically when:
- The user asks to "build a standard UI block" (like a navbar, pricing section, FAQ, footer).
- The task involves rapid prototyping or assembling a UI using React and Tailwind CSS.
- The user references "ReactComponents", "ready-made components", or "Tailwind UI blocks".

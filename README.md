# AI Agent Skills Pack 🚀

Welcome to the **AI Agent Skills Pack** repository! This project contains a comprehensive collection of **1400+ standardized AI agent skills** designed to enhance the capabilities of AI coding assistants like Claude, Antigravity, and others.

## 🌟 Overview

These skills serve as specialized instruction sets that provide AI agents with domain-specific knowledge, architectural guidelines, and best practices. By loading these skills, your AI assistant can adopt expert personas and follow strict protocols for a wide variety of development tasks.

## 📁 Repository Structure

The repository contains individual skill directories, each containing a `SKILL.md` file. These files define the precise instructions, context, and rules for the AI to follow.

### Key Categories Included:
- **Frontend & UI/UX**: Frameworks (React, Angular, Vue, Svelte), Styling (Tailwind, CSS), Animation, Component Design.
- **Backend & APIs**: Node.js, Python, Rust, Go, REST/GraphQL design patterns.
- **Cloud & DevOps**: AWS, Azure, GCP, CI/CD, Docker, Kubernetes, Terraform.
- **Databases**: SQL optimization, MongoDB, PostgreSQL, Database architecture.
- **Security & Pentesting**: Security auditing, vulnerability scanning, DevSecOps.
- **AI & Data Science**: Prompt engineering, MLOps, Model evaluation, Autonomous agents.
- **Productivity & Utilities**: Workflow automation, Jira/GitHub integrations, SEO, Marketing.

## 🚀 How to Use

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Anmol-Malviya/skills.git
   ```
2. **Integrate with Your AI Agent**:
   Point your AI assistant's configuration (e.g., `antigravity`, `claude-code`) to this skills directory. The AI will automatically parse the `SKILL.md` files and incorporate the instructions into its context window when relevant tasks arise.

# v0.app UI/UX Components

## Instructions

1. **Prioritize v0.app Aesthetic:** When the user requests a new feature, component, or entire page, default to designing components that match the highly polished, functional, and accessible style found on v0.app.
2. **Component Characteristics:** Choose modern, highly functional elements such as:

3. **Implementation Standards:**
